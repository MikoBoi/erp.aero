Для запуска проекта необходимо установить Docker
В корне папки открываем командную строку, вводим следующую команду:  docker build -t pdf_project .
После успешной сборки, проект готов к запуску.
Вводим следующую команду, чтобы запустить 1 и 2 задания: docker run --rm pdf_project python main.py
Вводим docker run --rm pdf_project python main.py 3, чтобы запустить дополнительное задание.
